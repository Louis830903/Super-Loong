# 战略规划业务闭环

## 目标
实现"一句话完成战略规划"：用户提出战略问题，Agent 自动完成完整分析流程。

## 闭环流程

```
用户提出战略问题
    ↓
[1/6] 信息收集 → web_search / http_request 收集行业数据
    ↓
[2/6] 竞品分析 → 识别主要竞品，提取优劣势
    ↓
[3/6] SWOT 生成 → 基于收集信息生成 SWOT 矩阵
    ↓
[4/6] 策略建议 → LLM 生成 3-5 个策略选项
    ↓
[5/6] 行动计划 → 每个策略拆解为可执行任务
    ↓
[6/6] 报告导出 → Markdown 战略报告 + 行动清单
    ↓
交付：战略报告 + 行动计划 + 风险提示
```

## 使用方式

### 方式一：一句话指令
```
"帮我分析电商行业的竞争格局，制定进入策略"
```

### 方式二：分步指令
```
"先收集新能源汽车行业信息，然后做 SWOT 分析"
```

## 分析框架

### PESTEL 分析（宏观环境）
- Political: 政策法规
- Economic: 经济趋势
- Social: 社会文化
- Technological: 技术变革
- Environmental: 环境因素
- Legal: 法律合规

### Porter 五力（行业竞争）
- 现有竞争者
- 潜在进入者
- 替代品威胁
- 供应商议价能力
- 买方议价能力

### SWOT 矩阵
- Strengths: 内部优势
- Weaknesses: 内部劣势
- Opportunities: 外部机会
- Threats: 外部威胁

## 输出交付物

1. **战略分析报告**（`strategy_report.md`）
   - 执行摘要
   - 环境分析
   - 竞争格局
   - SWOT 矩阵
   - 策略建议
   - 行动计划

2. **行动清单**（`action_items.xlsx`）
   - 任务名称
   - 负责人
   - 截止时间
   - 优先级
   - 依赖关系

3. **对话摘要**（直接回复）
   - 核心结论（3 句话）
   - 关键风险（2 个）
   - 下一步行动（1 个）

## 示例对话

**用户**: "分析跨境电商市场，制定我们的进入策略"

**Agent 执行**:
1. `web_search` 收集跨境电商行业报告
2. `http_request` 获取竞品数据
3. LLM 生成 SWOT 分析
4. 生成 3 个策略选项（差异化/成本领先/聚焦）
5. 拆解为 10 个具体行动项
6. 回复: "分析完成！建议采用差异化策略，聚焦细分市场。核心风险：物流成本上升、政策变化。详细报告已生成。"

## 依赖工具

| 工具 | 用途 |
|------|------|
| `web_search` | 收集行业信息 |
| `http_request` | 获取竞品数据 |
| `data_insight` | 分析收集到的数据 |
| `xlsx_write` | 导出行动清单 |
| `todo_manage` | 创建任务列表 |

## 注意事项

- 信息收集需注明来源
- 策略建议需考虑资源约束
- 行动计划需可执行、可衡量
- 定期回顾和调整策略
