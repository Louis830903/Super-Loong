# Super-Agent (Super Loong)、OpenClaw 和 Hermes Agent 三项目全面对比

---

## 一、项目定位与架构概览

| 维度 | OpenClaw | Hermes Agent | Super-Agent (Super Loong) |
|------|----------|-------------|--------------------------|
| 定位 | 个人 AI 助手，本地运行 | 自我改进的 AI Agent，研究级 | 模块化通用 AI Agent 平台，面向国内 |
| 语言 | TypeScript (全栈) | Python (全栈) | TypeScript (核心/API/前端) + Python (IM网关) |
| 架构 | 单体 npm 包 | 单体 Python 项目 | Monorepo (pnpm workspace) |
| 代码规模 | ~10万行+，src/ 94个目录 | cli.py 44万字符，run_agent.py 53万字符 | 核心较精简，三层包 core/api/web |
| 维护方 | 开源社区 | Nous Research | 你的团队（Super Loong 品牌） |

## 二、核心功能模块对比

### 2.1 记忆系统

| 能力 | OpenClaw | Hermes Agent | Super-Agent |
|------|----------|-------------|-------------|
| 记忆层次 | Markdown 文件（USER.md, MEMORY.md, SOUL.md）+ QMD 搜索注入 | 多后端插件（Honcho/Mem0/Holographic/Hindsight 等 8 种） | 三层架构：Core（常驻）+ Recall（对话）+ Archival（长期） |
| 持久化 | 本地文件，手动编辑 | Honcho 云端 + 本地记忆工具 | SQLite（sql.js WASM）+ 可插拔后端 |
| 向量编码 | 无原生向量搜索 | HRR 相位编码（holographic.py） | HRR 相位编码（从 Hermes 移植的 hrr.ts，跨语言一致） |
| 语义搜索 | QMD 文件搜索（文本匹配） | FTS5 全文搜索 + Honcho 语义搜索 + LLM 摘要 | HRR 向量相似度 + SimpleEmbedding 兜底 |
| 记忆工具 | 无 Agent 可调用的记忆工具 | memory_tool.py + Honcho 4 工具（context/search/profile/conclude） | remember/recall/forget + core_memory_read/append/replace |
| 注入安全 | 无注入防护 | 无 | injection-guard.ts 扫描 + 清洗 |
| 实体解析 | 无 | 无独立模块 | entity-resolver.ts 实体提取与别名解析 |

> **关键差异**：OpenClaw 是纯文件型记忆，手动维护；Hermes 通过 Honcho 实现云端持久化和 dialectic 推理（AI-to-AI 问答）；Super-Agent 融合了 Letta 三层 + Mem0 可插拔 + MemSkill 工具化三种思路，并加入 HRR 向量符号架构和安全扫描。

## 三、技术架构特点

### 3.1 OpenClaw

- **纯 TypeScript 全栈**：前后端一体，npm 包分发，Node.js 运行时
- **插件体系最成熟**：channels/plugins/ 123 文件，plugin-sdk/ 393 文件
- **网关即核心**：gateway 是控制面，WebSocket 双向通信
- **配置系统复杂**：config/ 265 文件，运行时热重载
- **安全体系完善**：security/ 77 文件，secrets/ 107 文件
- **测试覆盖高**：大量 .test.ts 文件伴随源码

### 3.2 Hermes Agent

- **纯 Python 全栈**：CLI 为主，单进程 agent loop
- **自我改进闭环**：nudge → 技能创建 → 自我改进 → 会话搜索 → 知识持久化
- **记忆后端最丰富**：8 种记忆插件（Honcho/Mem0/Holographic/Hindsight/ByteRover/OpenViking/RetainDB/SuperMemory）
- **Honcho dialectic**：独特的 AI-to-AI 推理层，AI peer 跨会话建模
- **研究就绪**：batch trajectory 生成 + Atropos RL 环境 + trajectory 压缩
- **终端后端多样**：local/Docker/SSH/Daytona/Singularity/Modal 六种

### 3.3 Super-Agent (Super Loong)

- **混合语言 Monorepo**：TypeScript (core/api/web) + Python (im-gateway)
- **三层记忆 + HRR**：Letta 三层架构 + HRR 向量符号（跨语言一致）
- **10 层提示工程**：prompt/ 7 文件，系统化的 guidance 常量
- **安全三级沙箱**：security/ 模块化隔离
- **自我进化引擎**：融合 Hermes nudge + MemSkill 失败分析，881 行完整实现
- **面向国内**：中文 LLM + 国内 IM 平台 + 注入防护支持中文
- **零外部依赖运行时**：sql.js (WASM SQLite)，无需安装数据库

## 四、演进路径：OpenClaw → Hermes → Super-Agent

### 4.1 从 OpenClaw 到 Hermes

迁移脚本明确了映射关系（`openclaw_to_hermes.py`，2793 行）：

| OpenClaw 来源 | Hermes 目标 |
|--------------|------------|
| SOUL.md | Hermes persona 配置 |
| MEMORY.md | Hermes 长期记忆条目 |
| USER.md | Hermes 用户 profile 记忆 |
| AGENTS.md | workspace 指令文件 |
| 技能目录 | `~/.hermes/skills/openclaw-imports/` |
| 频道配置 | Hermes gateway `.env` |
| API keys | Hermes `.env` |

**核心改进**：
- 记忆从磁盘文件升级为 Honcho 云端 + 语义检索
- 技能从静态目录升级为可自我学习、自我改进的闭环
- CLI 从 Node.js 切换为 Python，运行更灵活

### 4.2 从 Hermes 到 Super-Agent

源码注释明确了融合来源：

| 源文件 | 融合注释 |
|--------|---------|
| guidance.ts | *"Fused from Hermes Agent ... and OpenClaw ... with Super Agent enhancements targeting Chinese LLMs"* |
| hrr.ts | *"移植自 Hermes Agent holographic.py，TypeScript 实现保持跨语言互操作性"* |
| engine.ts | *"Nudge System (Hermes-style)"* + *"Skill Evolution (MemSkill-style)"* |
| orchestrator.ts | *"Task Orchestration (CrewAI-style)"* + *"Conversation Negotiation (AutoGen-style)"* |
| manager.ts | *"Three-layer architecture (inspired by Letta)"* + *"Pluggable backends (inspired by Mem0)"* + *"Agent tools (inspired by MemSkill)"* |

**核心改进**：
- **语言转换**：Python → TypeScript 核心 + Python 网关微服务
- **记忆系统升级**：单一后端 → 三层架构 + HRR 向量 + 注入防护
- **架构解耦**：单体 → Monorepo 三包分离（core/api/web）
- **中国适配**：中文 LLM 适配 + 国内 IM 平台 + 中文注入防护
- **Web UI 全新**：Next.js 16 前端 13 个页面
- **零依赖运行时**：sql.js WASM 替代外部数据库

## 总结

三个项目构成了一条清晰的技术演进链——**OpenClaw** 提供了成熟的插件体系和广泛的平台覆盖，**Hermes** 引入了自我改进闭环和 Honcho 记忆革新，**Super-Agent (Super Loong)** 则在两者基础上实现了架构现代化（Monorepo + 微服务）、记忆系统升级（三层 + HRR + 安全）、中国市场适配（国内 IM + 中文 LLM），定位为面向国内的生产级 AI Agent 平台。
