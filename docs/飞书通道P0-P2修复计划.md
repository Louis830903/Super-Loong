## Task 1: Phase A — P0 致命问题修复（预计 2h）

### Task 1.1: P0-04 — outbound `_ensure_client` 空指针修复
- **文件**: `services/im-gateway/channels/feishu/outbound.py` L252-259
- **问题**: 若 `configure()` 未被调用，`self._token_manager` 为 `None`，`get_token()` 抛 `AttributeError`
- **修复**: 在 `_ensure_client` 开头添加 `None` 检查和 `has_credentials()` 检查，抛出明确 `RuntimeError`
- **验证**: 不调用 `configure()` 直接调用 `send_text()` → 确认抛 RuntimeError 而非 AttributeError
- **预估**: 15min

### Task 1.2: P0-01 — sender_name 安全解析
- **文件**: `services/im-gateway/channels/feishu/gateway.py` L260-268
- **问题**: `getattr(sender, "sender_id", {}).union_id` 当对象不含 `union_id` 时抛 AttributeError，整个 `_on_message_event` 中断，消息被静默丢弃
- **修复**: 改为 `getattr(getattr(sender, "sender_id", None), "union_id", "") or ""`，同时修复 L263 的 `user_id` 解析
- **验证**: 构造 `sender_id=None` 边界值 → 确认无异常 + MessageEvent 正确填充
- **预估**: 20min

### Task 1.3: P0-03 — 出站消息重试+成功日志+截断（含 P1-06）
- **文件**: `services/im-gateway/channels/feishu/outbound.py` L106-128 + `core/message_pipeline.py` L254-294
- **问题**: `send_text` 失败仅记日志无重试；超长消息直接 400
- **修复**:
  1. `outbound.py send_text`: 添加超长截断（>4000 字符截断+警告日志）+ 成功日志
  2. `message_pipeline.py _send_reply`: 增加 1 次重试（间隔 1s）+ 结构化日志
- **验证**: Mock `send_text` 首次 `success=False` → 自动重试；发送 5000 字符 → 截断成功
- **预估**: 50min

### Task 1.4: P0-02 — `_send_reply` 传递 thread_id
- **文件**: `services/im-gateway/core/message_pipeline.py` L140-142
- **问题**: `_send_reply` 只传 `chat_id`，不传 `thread_id` 和 `msg_id`，飞书群话题回复失效
- **修复**: 扩展调用 `await self._send_reply(channel_id, event.source.chat_id, reply_text, thread_id=event.source.thread_id, msg_id=event.msg_id)`，同步扩展 `_send_reply` 签名
- **验证**: 飞书群话题中发消息 → Agent 回复在同一话题；单聊 thread_id="" 不影响
- **预估**: 20min

## Task 2: Phase B — P1 重要问题修复（预计 2h）

### Task 2.1: P1-03 — 飞书消息处理异常缺少 traceback
- **文件**: `services/im-gateway/channels/feishu/gateway.py` L284-285

### Task 2.2: P1-01 — WebSocket 连接成功判断增强
- **文件**: `services/im-gateway/channels/feishu/gateway.py` L158-173

- **验证**: `pnpm build` 编译通过 + requestId 去重仍正常

### Task 2.4: P1-04 — Bridge WS 断开后 pending futures 优雅降级
- **文件**: `services/im-gateway/bridge.py` L599-608
- **问题**: 通过 `set_exception` 导致上层非预期异常
- **修复**: 改为 `set_result({"text": "连接中断，正在重试...", "attachments": []})` 优雅降级
- **预估**: 15min

### Task 2.5: P1-05 — flush_loop 封装修复
- **文件**: `services/im-gateway/bridge.py` + `server.py` L302, L374-376
- **问题**: `bridge._client` 直接访问私有属性，破坏封装
- **修复**: 在 `AgentBridge` 添加 `is_ready` 属性和 `post()` 公共方法；`server.py` 改用公共接口
- **预估**: 20min
